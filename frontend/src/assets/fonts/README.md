# Roboto web fonts

Normal variable Roboto, with weights 400–700, downloaded from Google Fonts.
The Cyrillic and Latin subsets include the Russian text, Latin text, numbers,
and punctuation used by this app. The browser downloads fonts from the app;
no runtime request to Google Fonts is needed.

- [Roboto on Google Fonts](https://fonts.google.com/specimen/Roboto)
- [Cyrillic WOFF2 source](https://fonts.gstatic.com/s/roboto/v51/KFO7CnqEu92Fr1ME7kSn66aGLdTylUAMa3iUBGEe.woff2)
- [Latin WOFF2 source](https://fonts.gstatic.com/s/roboto/v51/KFO7CnqEu92Fr1ME7kSn66aGLdTylUAMa3yUBA.woff2)
- [Original CSS](https://fonts.googleapis.com/css2?family=Roboto:wght@400..700&display=swap)
- [License source](https://github.com/google/fonts/blob/main/ofl/roboto/OFL.txt)

See `OFL.txt` for the SIL Open Font License.

Segoe UI is referenced as an installed system font only. No Segoe UI font
files are distributed with this project. On systems without Segoe UI, the
base font falls back to the bundled Roboto. Hosting Segoe UI would require
an appropriate webfont license and the licensed font files.
